# Historias de usuario

Las siguientes historias describen las necesidades de los usuarios
del marketplace de productos para mascotas.

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero buscar productos y consultar sus características, precio y disponibilidad, para elegir el que necesito. |
| HU02 | Como seller, quiero registrar, actualizar y consultar mis productos, para mantener mi oferta disponible y actualizada. |
| HU03 | Como cliente, quiero agregar productos al carrito, modificar sus cantidades y retirarlos, para organizar mi compra. |
| HU04 | Como cliente, quiero registrar mi dirección de entrega y generar un pedido con los productos del carrito, para solicitar mi compra. |
| HU05 | Como administrador, quiero registrar, actualizar y desactivar sellers, para controlar qué vendedores pueden ofrecer productos en la plataforma. |
| HU06 | Como cliente, quiero consultar el detalle y el estado de mis pedidos, para conocer el avance de mis compras. |
| HU07 | Como cliente, quiero pagar mi pedido mediante una pasarela de pago y conocer el resultado, para saber si mi pago fue aceptado. |
| HU08 | Como cliente, quiero consultar el estado del envío de mi pedido, para conocer el avance de su entrega. |
| HU09 | Como cliente, quiero consultar el comprobante de mi compra, para contar con una constancia del pago realizado. |
| HU10 | Como seller, quiero consultar los pedidos y las ventas correspondientes a mis productos, para organizar su atención. |
| HU11 | Como cliente, quiero crear una cuenta e iniciar sesión, para realizar compras y consultar mis pedidos. |
| HU12 | Como seller o administrador, quiero iniciar sesión con mi cuenta, para acceder a las funciones que me corresponden. |
| HU13 | Como administrador, quiero gestionar las cuentas y los roles de los usuarios, para controlar el acceso a las funciones de la plataforma. |
| HU14 | Como cliente, quiero consultar la disponibilidad de productos actualizada con la información del ERP, para decidir mi compra con información vigente. |

## Relación con los sistemas externos

- HU07 requiere la integración con la pasarela de pago.
- HU08 requiere información del servicio de envío.
- HU09 requiere la integración con el servicio de facturación.
- HU14 requiere consultar la información de productos y stock del ERP.

Estas historias expresan las necesidades de los usuarios. Los requisitos
funcionales detallarán qué debe hacer el sistema para atenderlas.
