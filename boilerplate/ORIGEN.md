# Origen del proyecto de referencia

Este directorio contiene el ejemplo proporcionado por la docente
Ing. Lizbeth Jaico Quispe para la Guía 03 del curso Arquitectura
de Software IS-488.

- Repositorio original: https://github.com/devlizbethjaico/boilerplate
- Fork del estudiante: https://github.com/SebastianCH27/boilerplate
- Commit de origen: 9291c711462caa603514669655b80897cc9df89c
- Fecha de incorporación: 28 de septiembre de 2026.

Los archivos se incorporaron mediante una descarga ZIP del fork.

El ejemplo se utilizará para ejecutar la aplicación, revisar sus
pruebas y analizar la separación entre dominio, aplicación,
infraestructura y presentación.

El código base corresponde al proyecto de la docente.
El análisis y las decisiones arquitectónicas del estudiante
se documentan en analisis-de-sistema/ y arquitectura/.
